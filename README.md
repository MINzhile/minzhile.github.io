# MINzhile · 行旅随记

记录人生感悟，也记录人生旅程。

网站：<https://minzhile.github.io>

这是一个 GitHub Pages 个人网站。视觉结构参考 Kevin Kelly 的个人网站：大幅风景图、简洁导航、分区文字；本站的文字、版式实现与配图另行制作。

## 从思源发布（推荐）

1. 在思源保留私人原稿，单独整理一份确认可以公开的文章。
2. 打开 [发布助手](https://minzhile.github.io/write/)，填写标题、日期、分类、简介和正文。
3. 点击「检查并预览」。助手会检查空字段、分类、未来日期、模板残留和思源内部图片/文档链接；它不能判断所有隐私问题。
4. 阅读预览，确认可以公开后，勾选确认框并下载文章文件。
5. 在助手中点击「到 GitHub 上传文章」，将下载的文件上传到 `_posts`，点击 Commit changes 确认提交。
6. 等待 GitHub Pages 发布成功，刷新网站查看。

发布助手无需登录。输入内容仅保留在当前页面内存，不发送到服务器、不自动保存；刷新或关闭会丢失尚未下载的内容。下载的文件保存在本机。

如需照片，请先整理公开版照片并上传到 `assets`，正文使用 `/assets/照片文件名.jpg`。思源导出的正文与附件需要一起处理；助手会提示尚未转换的内部链接。

**公开边界：** 当前仓库是公开的，上传进去的文件和提交历史都可能被访问。`published: false` 或从首页隐藏，不能保护仓库里的原稿。私人稿件留在思源。

## 直接在 GitHub 写作

仍可在 `_posts` 中创建 `YYYY-MM-DD-英文短标题.md`，文件开头填写 `title`、`date`、`category`、`description`。推荐先用发布助手生成，避免将文件名误当标题或提交模板文字。分类使用 `感悟` 或 `旅程`。

## 添加照片

把照片上传到 `assets` 文件夹，在文章中写：

```markdown
![照片内容说明](/assets/你的照片文件名.jpg)
```

## 修改主页

- `index.html`：首页的关于文字、导航和分区。
- `_config.yml`：网站标题、描述和网址。
- `assets/site.css`：页面样式和手机布局。
- `_posts`：所有已经发表的文章。
- `_layouts/post.html`：文章阅读页。

首篇《给人生，留一个自己的地方》是依据建站时表达的想法整理的开篇文字，可直接修改或删除。旅程栏目未填入虚构经历。

## GitHub Pages 设置

在 **Settings → Pages** 中选择 **Deploy from a branch**，分支 `main`，文件夹 `/ (root)`。

GitHub 会自动使用 Jekyll 生成网站，无需自行安装软件或购买服务器。
