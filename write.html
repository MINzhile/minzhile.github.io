把文字，准备好再分享。

从思源复制已经整理好的公开版正文。在这里检查、预览，然后下载文章并上传到 GitHub。

输入只在当前页面处理，不自动保存或上传。刷新或关闭页面前请下载。私人原稿继续保存在思源。

支持 Markdown 标题、列表、引用、链接和表格。不要粘贴开头的文章信息区。图片先上传到公开仓库的 assets 文件夹，再使用 /assets/照片.jpg；思源内部链接需要转换。

发布前预览

为避免向外部网站发送请求，预览中的图片以说明文字展示，链接不可点击。最终排版以网站为准。

没有下载成功？复制文章内容

在 GitHub 的 _posts 文件夹选择 Add file → Create new file，使用下方文件名，粘贴完整内容后提交。

下载后，到 GitHub 上传文章 ↗，选择下载的文件，再点击 Commit changes 确认。等待发布完成后刷新首页。

检查只针对格式与常见模板错误，不能自动判断所有隐私问题。上传到公开仓库后，源文件和提交历史也可能被访问。
